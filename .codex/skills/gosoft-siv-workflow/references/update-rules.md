# Update Rules

Update the repo memory files when any of the following changes:

- Local scripts under `scripts/`
- Boot ports or URLs
- Backend or frontend scaffold layout
- Seed behavior or seed output format
- Validation milestones and blockers

Minimum updates after each meaningful session:

- `WORKLOG.md`: what changed
- `NEXT_STEPS.md`: what should happen next
- `ARCHITECTURE.md`: only if the shape of the system changed
- `README.md`: if setup or run instructions changed
